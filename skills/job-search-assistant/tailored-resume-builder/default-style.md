# Resume style
Style format: 1
Source: plugin default

The look used for tailored resumes when the user's profile names no resume style of their own:
a clean single-column layout that applicant-tracking systems read well. Format reference:
resume-style-format.md in this skill's folder.

## Page
- Size: Letter
- Margins (in): top 0.5, bottom 0.5, left 0.6, right 0.6

## Text
- Body: Calibri, 10.5
- Name: Calibri, 20, bold, caps, color 1F3864
- Headline: Calibri, 11, bold, caps, color 404040
- Contact: Calibri, 9.5, color 404040
- Section headings: Calibri, 11, bold, caps, color 1F3864, rule
- Company: bold
- Company description: italic, color 595959
- Role: bold
- Location: italic
- Dates: color 404040

## Layout
- Header alignment: left
- Contact separator: " · "
- Section order: summary, competencies, highlights, experience, education, certifications, additional
- Section titles: summary = ; competencies = Core Competencies; highlights = Career Highlights; experience = Professional Experience; education = Education; certifications = Certifications; additional = Additional Information
- Competencies: grid 3
- Bullet: •
- Dates: right
- Accomplishments label:
- Space after section heading (pt): 3
- Space between roles (pt): 6

## Not carried over
- Nothing; this is the plugin's own style.
