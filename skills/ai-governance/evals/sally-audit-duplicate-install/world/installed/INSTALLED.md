# Installed skills visible in this session

The full installed folder of each skill is readable under `installed/<skill>/`. The `personal-productivity` plugin from the esscott-claudecowork marketplace is also installed; its skills appear namespaced as `personal-productivity:<skill>`, and their folders are under `installed/personal-productivity/<skill>/`.

| Skill | Method |
|---|---|
| job-lead-intake-scan | standalone |
| job-lead-tier2-scoring | standalone |
| sally | standalone |
| sally-audit | standalone |
| personal-productivity:job-lead-intake-scan | plugin (personal-productivity 1.0.0) |
| personal-productivity:job-lead-tier2-scoring | plugin (personal-productivity 1.0.0) |
